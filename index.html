Priority items

Any order containing one of these (matched inside the item name or SKU) jumps to the top of the queue. One per line. Example: break, slab, PSA 10.

Order combining

By default every order is its own position. Turn on combining to merge a buyer's repeat orders that arrive close together. Not retroactive — it applies to orders placed after you save.

Add event

Matching order items (by keyword) are pulled out of the main queue into this event's side-queue. Spots fill in the order they're bought.

Display name

Change the name shown for this buyer everywhere (queue, overlay, Discord). Leave blank to clear the override and go back to their real name.
