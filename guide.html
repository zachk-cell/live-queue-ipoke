Operator Quick-Start

Live Queue Guide

Everything you need to run the live order board for your first stream. Skim it once before you go live, keep it open on the side, and you'll be fine.

What this is (10-second version)

When you're live on TikTok, every paid order drops into this board automatically, newest work at the top. You pack from the top down: print the bag label, drop the cards in, hit Fulfilled. Colored flags tell you when an order needs a second look. That's the whole job.

🧪 Want to practice? Open the interactive sandbox ↗ — a safe copy of this panel loaded with fake orders. Add orders, print labels, fulfill, bump, undo… you can't break anything, and it never touches the real queue. Perfect for training a new helper before a live.

1 Get in

  • Open the admin link you were given (it's a secret URL — don't share it or post it on stream).
  • Log in with the password and the 2FA code from the authenticator app.
  • First thing every session: press Ctrl+Shift+R (hard refresh) so you're on the newest version.
Two views: the public page (root URL) shows buyers only their position and username — no prices, no controls. The admin panel (the secret URL) is where you work. Never screen-share the admin panel on stream.

2 Start the stream

Hit ● Go Live. The dot by the title turns green and the badge reads LIVE. From now on, paid orders flow in on their own (usually within ~10 seconds of the buyer paying).

Important: an order only appears once TikTok marks it paid / awaiting shipment. If a buyer just checked out but hasn't paid, it won't show yet — that lag is TikTok, not the board.

3 Read the board

Here's a full board mid-stream. Each row is one buyer's bag. Top bar shows the running totals (in queue, priority, value, fulfilled).

🔍 Click the image to enlarge · A queue row, left to right: ✕ remove · position # · username + flags + order numbers · caret ▸ (expand) · 🏷 Label · price · ▲ bump · ✓ Fulfilled.

Two timers help you read how the line is flowing:

  • Time in queue — each row shows how long that buyer has been waiting since their first order this stream. The top bar shows the average wait across the line.
  • Time at top — once a buyer reaches #1, a timer shows how long they've been up (i.e. how long packing is taking). It runs only for the current #1; if a priority order or a bump pushes them down, that timer clears and only restarts if they reach the top again. The top bar shows the average fulfillment time — how long orders sat at #1 before you marked them done.

4 The flags — what they mean & what to do

These little badges are the whole point. Learn these and you're set:

FlagMeansDo this
PRIORITYContains a priority item (e.g. a break) — auto-jumped up.Handle it ahead of normal orders.
＋ ADDED MORE ×2Good news. This buyer (currently #1) ordered again while you're packing them. The ×N counts how many times.Add the new item(s) to the bag you're already building before you seal it.
⚠ CANCEL REQStop. TikTok put this order on hold — almost always a buyer asking to cancel.Do not ship it. Check the order in TikTok Shop before packing.
⚠ SAME NAME id …1111Two different buyers share the same display name.Use the id … tag / order number to give the right bag to the right person.
🔁 2 earlier todayThis buyer already had order(s) fulfilled earlier this stream.Consider whether it should be combined into one shipment.
2 ordersMultiple orders merged into one bag for this buyer.Pack them together; expand to see everything.

A red-outlined row = cancel/hold. A green-outlined row = added-more. A gold row = priority. A blue-outlined row = you bumped it to the top.

5 Work an order (the loop you'll repeat all night)

  1. Click the caret ▸ to expand the row and see every item.
  2. Hit 🏷 Label to print the bag label on the thermal printer, and pack the cards.
  3. Hit ✓ Fulfilled — the row moves down to Fulfilled this stream.
  4. Move to the next row down. That's it.

The other buttons

  • ⭐ Priority items — set the words that auto-jump an order to the top (e.g. break, slab). Any order whose item name contains one of these becomes PRIORITY. Edit them anytime and the board re-sorts instantly.
  • ↩ Undo (in Fulfilled) — marked one done by mistake? Puts it back in the queue.
  • ▲ Bump — jump a buyer to the very top (beats priority). Use sparingly.
  • ✕ Remove — buyer cancelled? Sends it to Cancelled (where you can ↩ Restore it).

7 The Piggy Bank counter (bundle stores only)

If your store runs the bundle counters, you'll see a Piggy Bank Counter card on the admin panel and a matching Piggy Bank Tracker on the public page. It tallies how many of each bundle variant have gone out.

  • How it counts. A variant ticks up +1 per unit the moment an order containing it reaches the top of the queue — not when it's ordered, and not when it's fulfilled. If a buyer who's already at the top adds another bundle, that still counts.
  • It never resets on its own. The counts are cumulative and carry across every stream — Go Live does not zero them. They only change from a sale, a manual Save, or a Reset.
  • Editing a count. Type a new number and hit Save (e.g. to fix a miscount).
  • Resetting a count. Reset asks for a second confirmation before it zeroes that variant — so you can't wipe it by accident.
  • The safety log. Every Save and Reset is written to the Reset / edit log (with the number it was before), so if something gets reset by mistake you can look up the old value and Save it back.
Don't reset the Piggy Bank to "clear the board." Those counts are meant to persist across streams — resetting is only for genuine corrections, and it's logged either way.

8 Following along in Discord

Your queue is also mirrored into your Discord server, so mods can watch it and help out without touching the admin panel. It's the same queue — Discord just reflects it, and it stays in sync automatically.

  • The pinned queue message. The bot keeps one auto-updating message pinned in the channel showing the current running order. It refreshes every few seconds on its own — nobody needs to reload anything.
  • When the stream is offline the message reads 🔴 Queue closed. Orders reappear automatically the moment the next stream goes live.
  • The Piggy Bank tracker (bundle stores only). If your store tracks bundle variants, the bot also keeps a separate pinned message — 🐷 Piggy Bank Tracker — showing each variant's running count. It's always visible (even when the stream is offline, since the counts carry over) and updates on its own.

Mod slash commands

Mods can act on the queue right from Discord — handy when the packer's hands are full:

/queueShow or refresh the current live queue on demand.
/fulfillMark the top slot done — or a specific buyer by adding the optional buyer name. Same as hitting ✓ Fulfilled in the panel.
/bumpBump a named buyer to the very top (beats priority). Use sparingly.
It stays in sync both ways. Anything a mod does in Discord shows in the admin panel within a moment, and anything the packer does in the panel updates the Discord message — so the two never step on each other.

9 Wrap up the stream

  • Click Export CSV under "Fulfilled this stream" to save the packing/shipping list (opens clean in Excel). Do this before you close out.
  • Hit ■ End Live — it files the whole stream into Past streams and clears the board. The dot goes red.
  • Need an old stream later? Past streams ↗ keeps the last few, each with its own CSV.

Tip: the Fulfilled and Cancelled lists collapse — click their headers to fold them away when they get long.

10 Golden rules

Do
  • Hard-refresh (Ctrl+Shift+R) at the start of every stream.
  • Pack top-down; trust the order.
  • Export the CSV before you End Live.
  • Stop on a ⚠ CANCEL REQ and add items on a ＋ ADDED MORE.
Don't
  • Don't share or show the admin URL on stream.
  • Don't hit Reset mid-stream — it wipes the board (it's for clearing test data, not normal use).
  • Don't panic if the queue seems quiet — orders only appear once they're paid on TikTok.
